# SHADOW KNIGHT NINJA

Protótipo funcional de jogo ninja responsivo para celular.

## Importante
- As moedas são **virtuais** e não representam dinheiro real.
- Depósito e saque são **simulações** e não processam pagamentos.
- O protótipo não confirma envio de dinheiro real.
- Para pagamentos reais seria necessário integrar um provedor autorizado, autenticação, KYC/AML quando aplicável, regras legais e controles antifraude.

## Como executar
Requer Node.js 18+.

```bash
npm start
```

Depois abra:
http://localhost:3000

Painel administrativo:
http://localhost:3000/admin

O banco de dados do protótipo é persistido em `data/db.json`.
